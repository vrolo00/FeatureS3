position: fixed – Estoy siempre arriba

position: static (por defecto)

Es el valor por defecto de todos los elementos. No se “despega” del flujo normal de la página y no responde a top, left, right ni bottom.

STATIC

position: sticky

Es una mezcla entre relative y fixed. Se comporta normal hasta que hacemos scroll y llega a la posición indicada con top, donde se “pega” y se queda fija.

Yo soy sticky: me “pego” al hacer scroll

Haz scroll en esta página para ver cómo esta barra se queda fijada cuando llega al límite superior. Este comportamiento es muy útil para menús, cabeceras de tablas o mensajes de aviso que queremos mantener visibles mientras el usuario baja por el contenido.

position: relative

El elemento sigue ocupando su sitio, pero podemos moverlo desde su posición original usando top, left, right, bottom Esa posición original se sigue “reservando”.

RELATIVE

position: absolute

El elemento se saca del flujo de la página. Se posiciona respecto a su padre posicionado más cercano (el primer padre con position distinta de static).
